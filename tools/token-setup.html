JOLEEN’S COLLECTION · LOCAL SETUP

A key for new finds.

Enable photo uploads with a repository-specific GitHub token. This page encrypts it in your browser; only the encrypted credential is sent to this local server and published.

  1. Create a fine-grained GitHub token.
  2. Choose owner manuelbrack, select Only select repositories → license-plate-tracker, set an expiration, and grant Contents: Read and write. Keep other permissions disabled apart from mandatory metadata access.
  3. Enter the token below, choose a strong passphrase, and keep the passphrase somewhere safe for Joleen.

The encrypted token is public and can be guessed offline. Use the generator or six randomly chosen words. Replacing an old credential? Revoke the old token too; old encrypted copies remain in Git history.

This publishes the encrypted credential to GitHub and triggers a Pages update. Plaintext credentials are never saved by this helper. Keep this window open until publishing finishes.
